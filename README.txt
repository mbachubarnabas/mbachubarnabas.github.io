# Barnabas Mbachu — Remote Job Portfolio

## Before publishing
1. Open `index.html`.
2. Replace `YOUR-EMAIL@example.com` with your real professional email.
3. Review the wording and remove/modify anything that does not accurately describe your experience.
4. Upload `index.html` to a free static hosting service such as GitHub Pages.

## Suggested portfolio URL
If you use GitHub Pages, a URL can look like:
https://YOUR-GITHUB-USERNAME.github.io/

## Job application
When an application asks for "Portfolio / Website", use your published portfolio URL.

## Important
The portfolio intentionally describes Zendesk/Freshdesk work as practice projects. Keep that wording unless you have professional employment experience with those platforms.
